COMPILADOR

Compilador desarrollado en Python utilizando PLY y Tkinter, capaz de realizar análisis léxico, sintáctico y semántico mediante una interfaz gráfica.

Objetivos del proyecto

  • Diseñar un lenguaje de programación básico
  • Implementar un analizador léxico
  • Construir un analizador sintáctico
  • Detectar errores léxicos y sintácticos
  • Mostrar resultados mediante una interfaz gráfica
  • Aplicar principios de compiladores y lenguajes formales
